## 三条硬规则

1. 研发任务以 Issue 为准，聊天和口头安排不算数。
2. 代码合并 ≠ 任务完成，未验证的不拖到 `Done`。
3. **本仓库是公开仓库**：不提交密钥、口令、token、真实个人信息、
   内网地址、未公开的第三方接口细节。提交前自查。
