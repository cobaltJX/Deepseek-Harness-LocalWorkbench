# Notice

DSH Local Workbench is a local development configuration built on the
following projects.

## DeepSeek Harness

Project:

```text
https://github.com/deepseek-ai/deepseek-harness
```

The local `harness/` folder is based on this source tree. It is currently in
developer preview and may include compatibility-breaking changes.

## dsh-launcher

Project:

```text
https://github.com/Ruler4396/dsh-launcher
```

The local `launcher-source/` and `launcher-bin/` folders are based on this
project.

Please keep the original license and attribution files from both upstream
projects when distributing this repository.
