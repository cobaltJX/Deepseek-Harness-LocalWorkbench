## 规则

- 每个 Issue 必须有且只有一名 `Assignee`，验收人写在 Issue 正文里。
- 负责人变更必须在 Issue 里留言，不允许只在聊天里说。
- 单人开发时，负责人与验收人可以是同一人，但**验收动作要留证据**（评论 + 截图）。
